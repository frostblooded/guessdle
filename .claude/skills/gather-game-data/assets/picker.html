Game Data Picker

Categories

Fields found in the infobox cards of these pages, with how many pages have each. Tick the ones to import as attributes (up to 10; pictures go in their own Photo column). Rows missing a ticked field can't be imported, since Guessdle needs every value filled.

Rows

Click a value or press rename to correct it; edited values are marked and can be undone. Hover a picture and click Edit to pick the square that gets imported.

Import file

In Guessdle, open the game's editor, go to Entries, press Import entries and paste this.

Edit picture

Drag the square to move it and its corner to resize it. Only this square is imported, as the entry's photo.
